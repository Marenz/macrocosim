      Macrocosim reference
      
        
      
      
      
      
        
      Modes
      
        
        
          
      • The chrome's Microgrids / Scenarios buttons swap the main pane. The REPL panel opens in either mode: from the repl pill on a microgrid's Topology view, or with a backtick anywhere. Press 1 for Microgrids, 2 for Scenarios.
        • 
          
      • Mode preference persists in localStorage; refresh restores the last-picked mode + last-selected microgrid.
        • 
        
      
        
      Microgrids
      
        
        
          
      • The Microgrids mode opens a card grid of every registered microgrid (one per (make-microgrid …) form, plus any added via the + New microgrid card or POST /api/microgrids/create).
        • 
          
      • The ⇪ Import site… card creates a microgrid from a microgrid API site export: pick components.json and connections.json together (connections optional). Rated power bounds, battery capacity, SoC range and the grid's rated fuse current all carry over into the simulation.
        • 
          
      • Clicking a card drills into that microgrid's Topology + Dispatches sub-tabs. The ← Microgrids button in the header returns to the list; a small → name chip on the REPL form shows which microgrid the REPL's evals route to.
        • 
          
      • Each microgrid runs its own Microgrid gRPC server on [::1]:<port> (default 8800, 8810, 8820, …). PlatformAssets runs on a single shared port (default 9900).
        • 
          
      • Component ids are globally unique across the enterprise — copying a selection from one microgrid and pasting into another (Ctrl/Cmd+V) re-creates the structure with fresh ids.
        • 
        
      
        
      Aggregations
      
        
        
          
      • The metrics pill (top-right of the canvas) opens live site metrics — power, reactive power / PF, frequency — read from the same frequenz-microgrid client a production control app would use. The formulas pill next to it shows how each of those aggregates is derived from the topology; every #N in a formula is a link back to the canvas.
        • 
          
      • Pulse-bar pills — graph (✓ / ⚠) summarises validation warnings from frequenz-microgrid-component-graph; loopback is the Microgrid client status; density + TZ toggle visual options.
        • 
        
      
        
      Snapshots
      
        
        
          
      • Snapshots button (top right) — saves the selected microgrid's managed file under snapshots/<microgrid-id>/<name>.lisp; load to replay that state. Needs a selected, managed microgrid. Headless: macroctl snapshot save / load / list [--microgrid-id N].
        • 
        
      
        
      Topology canvas
      
        
        
          
      • Click a node — inspect it (charts + config + knobs in the floating inspector; click empty canvas or Esc to dismiss).
        • 
          
      • Shift+Drag on empty canvas — rubber-band a selection rectangle; nodes inside the box are selected.
        • 
          
      • Shift+Click a node — toggle that node into / out of the current selection (after a rubber-band, or to build one a node at a time).
        • 
          
      • Ctrl/Cmd+hold + drag from one node to another — create an edge between them.
        • 
          
      • Double-click a node — select it together with everything it feeds (its whole subtree). Shift+Double-click adds the subtree to the selection.
        • 
          
      • Right-click — context menu. With a selection: Copy, Cut, Delete. With two or more nodes selected, the menu grows the arrange tools: align as a grid / lanes / radial, align in a row / column, spread, mirror, and spacing. With nothing selected and a non-empty clipboard: Paste. Right-clicking a node not in the current selection resets the selection to that node first.
        • 
          
      • Layout picker (top-right of the canvas) — lanes (default), columns, top-down, radial. Dragging a node by hand keeps your arrangement; picking a layout resets it. The snap toggle makes dragged nodes snap to a grid; hold Alt while dragging to move along one axis only.
        • 
          
      • Ctrl/Cmd+C — copy selection. Ctrl/Cmd+V — paste. Ctrl/Cmd+X — cut. Each paste re-uses the last copy; clipboard captures structure only (categories + internal edges), so clones use category defaults.
        • 
          
      • Del / Backspace — delete selection. Ctrl/Cmd+A — select all visible. Esc — deselect.
        • 
          
      • Ctrl/Cmd+Z — undo the last canvas edit. Ctrl/Cmd+Shift+Z (or Ctrl/Cmd+Y) — redo. The history lives on the server, one step per structural edit of the microgrid's managed file, so it survives page reloads and is shared by every open tab.
        • 
          
      • The panels group (top-right of the canvas) summons the canvas-side floating panels (formulas, metrics, weather, repl, logs). formulas opens the formula explorer: pick a metric, hover a part of the formula to highlight its components on the canvas (subtracted parts show red), click a #N to jump to that component. The Engine options card changes how the formula is generated; all options are view-local. metrics opens the site metrics panel: foldable Power / Reactive power / Frequency cards, each a live chart over the derived aggregate streams, with chips that read out the latest value and toggle their series off the chart.
        • 
        
      
        
      Inspector + chrome
      
        
        
          
      • Inspector — one of the floating panels, alongside the formula explorer, metrics, weather, the REPL, the log tail, Defaults and the Report; each closes with its × or Esc (newest first). The inspector appears when you click a node (charts + config + knobs), and also closes when you click empty canvas or switch tab.
        • 
          
      • Docking — every panel's ⤓ button offers to dock it into a strip along the bottom or down the right edge of the window, where it becomes a tile and stops covering the canvas; a strip appears only while it holds a tile, and the bar beside it drags to change its size. The tile's ⤒ floats it back to where it was. Several docked panels share a strip: drag the bar between two tiles to trade space, drag a tile's head along the strip to reorder. A docked panel that you close comes back docked. You can also drag a floating panel's grab strip onto the bottom or right edge of the canvas to dock it there, and drag a tile's head out of its strip to float it again.
        • 
          
      • Add component — the + Add button at the top-left of the Topology canvas opens a palette: click a button and an auto-id'd component appears, with a color dot matching its node's category colour. hidden meter adds a meter the gRPC topology leaves out (its node draws dashed). Wire it via Ctrl/Cmd+drag.
        • 
          
      • Values — nodes show current power (and reactive power or SoC); the grid node shows the grid frequency, amber from 0.1 Hz away from 50 Hz and red from 0.2 Hz. Edges take the colour of the direction power actually flows (blue import, green export) and thicken with its magnitude. The values pill (top right) toggles the numbers; off, nodes show name and id only. Hovering a node on Topology opens a detail card.
        • 
          
      • Defaults — per-category defaults (Lisp values), opened in its own floating panel; edits write to enterprise.lisp.
        • 
          
      • Managed files — every microgrid is a file. A managed one (created here, or adopted) carries a macrocosim-generated block that is rewritten on each structural edit; an unmanaged one is hand-written, so its structure is read-only in the UI and its card carries an unmanaged chip. Hit Adopt in the microgrid header to take it over. An unsaved chip means a live edit the file could not record.
        • 
        
      
        
      REPL
      
        
        
          
      • Ctrl/Cmd+Enter — eval. Tab — complete.
        • 
          
      • The repl and logs pills on a microgrid's Topology view open the REPL and the server log tail as floating panels — drag, resize and close them like any other card. A backtick opens the REPL from anywhere; Esc in its input closes it. The Logs panel's show dropdown sets a minimum level (lines below it stay hidden) and clear empties the tail.
